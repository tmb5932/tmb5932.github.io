weather-buddy / build.log

Not every project needs to be some awesome learning experience or super cool; sometimes it should just be useful. Checking the weather usually means finding my phone and opening an app, so I built a little desk buddy instead.

hardware: ESP32-S3, custom PCB, TMP102 indoor temp sensor, 3.5in ST7796 SPI TFT (480×320), 3D-printed case
software: ESP-IDF v5.4, OpenWeather API client, SNTP time sync
  • Four-section dashboard (indoor temp, outdoor temp, weather icon/condition, date/time) updated region-by-region instead of full-screen redraws.
  • Self-contained WiFi and location setup: hold the button at boot to open a captive portal, enter WiFi credentials and coordinates from a phone, saved to NVS for future boots.
  • After setup, that same button toggles the display on/off; powered over USB-C.
